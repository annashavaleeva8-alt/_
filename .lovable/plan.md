

# Админ-панель для блога офтальмолога

## Что будет сделано

### 1. Подключение Lovable Cloud
- Настройка базы данных, авторизации и хранилища файлов через Lovable Cloud (Supabase)

### 2. База данных (миграции)

**Таблица `site_content`** — хранение редактируемого контента сайта:
- `id` (text, PK) — ключ блока (hero_title, hero_description, about_text и т.д.)
- `content` (text) — текстовое содержимое
- `image_url` (text, nullable) — ссылка на изображение
- `updated_at` (timestamp)

**Таблица `site_visits`** — аналитика посещений:
- `id` (uuid, PK)
- `visitor_ip` (text)
- `city` (text, nullable)
- `country` (text, nullable)
- `referrer` (text, nullable)
- `page` (text)
- `user_agent` (text)
- `created_at` (timestamp)

**Storage bucket** `site-images` — для загрузки фото с компьютера

**RLS-политики**: только авторизованный админ может редактировать контент; посещения записываются публично, читаются только админом.

### 3. Edge Function для трекинга
- `track-visit` — принимает данные о посещении, определяет геолокацию по IP (через бесплатный API ip-api.com), сохраняет в `site_visits`

### 4. Страница авторизации `/admin/login`
- Простая форма входа по email + пароль
- Защита маршрута `/admin` — только для авторизованных

### 5. Админ-панель `/admin`
Две вкладки:

**Аналитика:**
- Таблица посещений: дата, город, страна, страница, откуда пришёл
- Фильтры по дате
- Счётчик общего числа визитов

**Редактор контента:**
- Форма для редактирования текстов каждой секции (hero, обо мне, подход, услуги и т.д.)
- Загрузка фото через файловый input → сохранение в Storage bucket
- Предпросмотр текущего контента

### 6. Интеграция с лендингом
- Лендинг подтягивает контент из `site_content` (с fallback на текущие захардкоженные тексты)
- При загрузке страницы вызывается `track-visit` для записи посещения

## Технические детали
- Новые файлы: `src/pages/Admin.tsx`, `src/pages/AdminLogin.tsx`, `src/lib/supabase.ts`, `src/hooks/use-admin-auth.ts`
- Миграции для таблиц и RLS
- Edge function `track-visit`
- Маршруты в `App.tsx`: `/admin/login`, `/admin`
